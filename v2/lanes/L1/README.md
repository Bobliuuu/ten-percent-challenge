# Bonsai-8B skill router with user feedback (shipped folder)

Task: route a voice-assistant request to one of 7 skills (Alarm, Weather, Music, Calendar, Lists, News, Transport). The model answers with the skill word, generated by plain greedy decoding (no constrained decoding, no head, no lookup). Start model: Bonsai-8B (1-bit, lossless repack: `bits.bin` sign bits + `scales.bin` fp16 group scales + `small.pt` + tokenizer/config).

## Files
| file | what |
|---|---|
| `bits.bin`, `scales.bin`, `small.pt`, `index.json` | the weights (bit-exact repack of the released checkpoint) |
| `tokenizer*`, `vocab.json`, `merges.txt`, `config.json`, `chat_template.jinja`, `LICENSE`, `NOTICE.txt` | tokenizer, config, licence |
| `answer.py`, `feedback.py`, `bonsai_loader.py`, `common.py` | the two commands and their helpers |
| `skill_task.json` | the task: prompt template (`{t}` = request) and the label menu |
| `feedback_calib.jsonl` | 182 UNLABELED prompts (used only to protect old behaviour during an edit) |
| `patch.pt` | exists only after feedback was given; absent = untouched model |

Needs a CUDA GPU (about 17 GB), `torch`, `transformers==4.56.2`.

## 1. Answer
```
python answer.py --artifact . --task skill_task.json "wake me at six" "play some jazz"
python answer.py --artifact . --task skill_task.json --in requests.jsonl      # lines: plain text or {"text": ...}
```
One label per line. Uses `patch.pt` automatically if feedback was given.

## 2. Give feedback (annotated mistakes, at most 25)
`ann.jsonl`, one row per item the model got wrong: `{"text": "how long do I boil an egg", "label": "Recipe"}`. The label may be a word that is NOT in the menu.
```
python feedback.py --artifact . --task skill_task.json --ann ann.jsonl
```
This edits existing tensors in closed form (no training, no gradient) and writes `patch.pt` (default carrier `scale`: new values for the existing per-128-group scales of the 1-bit MLP `down_proj` of the last 6 layers, about 4.7 MB; no new tensor). Annotations are not stored. Running it again with an empty file removes the patch (the tree is byte-identical to the original).

Options (all optional):
| flag | effect |
|---|---|
| `--append` | continual feedback: keep the existing patch and add a new round (a second/third skill) on top of the already-patched model |
| `--carrier scale\|cols\|lr` | how the same edit is stored. `scale` (default, least adapter-like): no new tensor: only the existing per-128-group scales of the 1-bit `down_proj` change (weight = sign * scale), 4.72 MB as an overlay `patch.pt` (could be written into `scales.bin` in place for 0 extra bytes); strength default lam 100 for this carrier. `cols`: fp16 replacement columns, ~50 MB (the earlier default). `lr`: the same delta as rank-k fp16 factors, ~0.5 MB. `--append` works with `cols` and `scale` |
| `--aug N` | N extra surface variants (lowercase, "please", ...) of each annotated text: stronger with few annotations, but less selective (a shuffled-label control teaches more) |
| `--lam --awt --margin --layers --cols --ridge` | strength / protection knobs (defaults chosen on a selection split) |

## 3. One process: feedback and answers
```
python answer.py --artifact . --task skill_task.json --feedback ann.jsonl "how long do I boil an egg"
python answer.py ... --feedback ann.jsonl --save-patch ...      # also persist patch.pt
```
`--feedback` applies the same edit in memory before answering; without `--save-patch` nothing is written.

## Harness mode
`answer.py --artifact . --in view.json --out out.json` (view = `[{id, query, tools}]`, `query` = the full prompt) and `feedback.py --artifact . --annotations ann.jsonl` (rows `{id, query, tools, gold:[{"name": label}]}`).

## What the numbers say (see `v2/lanes/L1/REPORT.md`, section L1+)
Locked exam retention vs the start model 1.000; 7.16% of the fp16 size with the default `scale` patch (counted as a 4.72 MB overlay file; 7.44% with the `cols` carrier, 7.14% with `lr`); new skill `Recipe` is generated by greedy decoding on unseen items (about 0.90 with 25 annotations, 0.77-0.85 with 5-12); shuffled-label and empty-feedback controls stay at 0.00-0.01.
