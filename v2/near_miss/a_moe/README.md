# near_miss lane a: other MoE bases, expert prune + low-bit (no weight training)
Task (per coordinator update): EASY-A SKILL7 voice-skill routing (MASSIVE+CLINC150, 7 skills, real generated skill word), dev items only (v2/task_search/EASY items_dev, 682 SKILL7 items). Calibration: routing statistics from EASY calib prompts of SKILL7 only (182 prompts, disjoint from dev); GPTQ Hessians (gray) from calib of all EASY tasks. Locked exam NOT touched.
Method: per-layer uniform top-K expert keep by routing criterion (mass = sum gate prob, freq, reap = mean gate x mean expert-output norm, reapmass = total gate x mean norm), router rows of dropped experts removed; kept experts RTN (asymmetric, fp16 scale + b-bit zero, MSE clip search) or ternary or GPTQ (gray); attn/shared/dense 4-bit g128, embed+lm_head 4-bit g64, norms/router/biases fp16. K is the largest value with analytic packed bytes <= 9.9% of base fp16 (scales, zeros, router rows, kept-expert ids, tokenizer/config files, 30 kB code allowance counted).
Eval: vLLM 0.33 greedy generation (max 8 new tokens) on dequantised bf16 copy of the packed tensors; exact label word. Retention = P(candidate correct | base correct).
Files: nm.py (build + eval), ret.py (retention), mkrows.py (table), cfgs_*.json, results/{b2=Qwen1.5-MoE, dsv2l, olmoe}/ (per-item generations + size breakdowns), ROWS.md.
Caveats: (1) bytes are exact analytic packed counts; a bit-packed writer was not implemented, the evaluated model is the dequantised bf16 view. (2) dropping router rows changes the softmax denominators (no renormalisation, norm_topk_prob=False kept); norm_topk_prob=True is catastrophic (0.3%). (3) base accuracies: Qwen1.5-MoE 0.912, DeepSeek-V2-Lite 0.660, OLMoE 0.522 (weak bases).
