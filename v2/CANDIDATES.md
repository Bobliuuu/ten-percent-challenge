## 0. How to read the numbers (honesty conventions)

- **LOCKED** = scored on the shared sealed exam `v2/exam` (SKILL7: 2,744 items, 7 kinds of 344-420 items, 1,489 from sources never used for anything: HWU64 + MTOP; hashes in `v2/exam/MANIFEST.json`). It is "locked" only in our sense: built from public data by one agent, sealed by hash before any run, scored once per artifact by the lane. It is NOT the maintainer's exam. 532 of its 2,744 rows are tier `seen_tox` (text occurs only in old probe files of an unrelated task; never fitted on); `clean_only` drops them but then Lists (223) and Transport (236) have fewer than 300 items, so the rule-3 per-kind count is NOT met on clean_only. Every lane reports a clean_only row.
- **dev / SEL / REP** = development, selection and report splits of our own pools. Config choices were made on them; they are never pass evidence. Where a number says dev it is dev.
- **Retention** = P(candidate correct | base correct), real greedy generation of the label word, exact string match, Wilson 95% lower bound in brackets. One exam item = 0.04 pt (2,653 base-correct items); differences under about 0.3 pt are noise on the exam, under 0.5 pt on dev. Quantizer-draw noise on the exam was 0.08 pt (L9b, 3 draws); on dev with weaker recipes it was +-2 pt (dense 32B) and up to 10 pt sd when a draw collapses (X03).
- **Bytes**: "measured" = `v2/tools/bytes_audit.py` or the lane's own audit on the written tree (every shipped file: weights, scales, codebooks, tokenizer, code, feedback carrier, calibration files). "analytic" = bit-count arithmetic, no written file. Denominator = fp16 size of the start model (for L1/L2 the start model is the released low-bit model; see ruling B below).
- **Draws**: a draw = a different quantizer/calibration seed (compression draw) or a different set of <=25 annotations (feedback draw). Both are stated per entry.
- Feedback protocol (all entries, SKILL7): new label `Recipe` never in any prompt menu; <=25 annotations from `ann_pool` (tuned-on sources only); locked teach set = 164 unseen `Recipe` items (MTOP 100, CLINC 42, HWU64 15, MASSIVE 7; HWU64+MTOP+most of CLINC are cross-source); neighbours = 379 exam items (all Lists + food/shopping keyword matches); arms: real, shuffled labels, wrong labels, empty. The new word is generated by the model's own forward pass in real generation.
